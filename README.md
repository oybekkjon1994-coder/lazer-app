# Lazer — ustaxona ilovasi

Lazer kesish narxi, o‘lchamdan DXF yasash, DXF import bilan nesting va buyurtmalar daftari — Android ilova.

APK har safar `main` ga o‘zgarish yuklanganda avtomatik yig‘iladi. Tayyor faylni **Releases** bo‘limidan `lazer.apk` sifatida yuklab oling.

## Telefonga o‘rnatish

Eng yangi APK: **Releases** → eng yuqoridagi versiya → `lazer.apk`.
